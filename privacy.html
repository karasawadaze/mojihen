プライバシーポリシー

最終更新日：2026年5月14日

「もじへん」（以下「本アプリ」）は、利用者のプライバシーを尊重し、個人情報の適切な保護に努めます。

1. 取得する情報

本アプリでは、以下の情報を取得する場合があります。

  • 入力された文章
  • 変換履歴
  • お気に入り情報
  • Firebase Authentication によるユーザー識別情報
  • 端末情報・広告識別子
  • 利用状況に関する情報

2. 情報の利用目的

  • 文章変換機能の提供
  • 履歴・お気に入り機能の提供
  • 不正利用防止
  • サービス改善
  • 広告配信

3. AI処理について

本アプリでは、入力された文章をAIによって変換するため、外部サーバーへ送信します。

文章変換には OpenAI API を利用しています。

4. 使用している外部サービス

  • Firebase Authentication（Google LLC）
  • Google AdMob（Google LLC）
  • OpenAI API（OpenAI, L.L.C.）

5. 広告について

本アプリでは Google AdMob を利用する場合があります。

広告配信事業者は、広告識別子等を利用して利用者に適した広告を表示することがあります。

6. データ保存について

変換履歴やお気に入り情報は、サービス提供のため保存される場合があります。

7. 情報の第三者提供

法令に基づく場合を除き、利用者情報を第三者へ販売・提供することはありません。

8. アカウント削除

利用者は、アプリ内の退会機能からアカウント削除を行うことができます。

9. ポリシー変更

本ポリシーは、必要に応じて改定される場合があります。

10. お問い合わせ

お問い合わせは、アプリ内の案内または公開ページよりご連絡ください。
